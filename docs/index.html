What it does

The whole drive is one map. The biggest things are the biggest boxes, and you fly into them.

Scans a whole drive in seconds

Run as administrator and SpaceSharp reads the NTFS file table directly instead of walking every folder, so a drive with a million files is mapped in a few seconds. Folders, other file systems and normal runs use a parallel folder walk.

A map you can fly into

Double-click a folder and the map zooms until it fills the window. Wheel to zoom around the cursor, drag to pan, Backspace to go up. Small files gather into one box until you zoom in close enough to see them.

Filters in plain words

Type videos over 500MB older than 1 year or *.iso and everything else dims. Six quick filters cover the usual cleanups. Select every match with one click, then delete them together.

Inspect anything

Ctrl+I on a file, folder or selection: exact size and size on disk, share of its folder and of the drive, counts, dates, the largest items inside and the space each file type takes, all with bars. Copy it as text.

Colors that show the hierarchy

Each top-level folder gets one hue, and everything inside keeps that hue, a step lighter per level. Or color by depth, or by file type with a legend. Six map styles and eight palettes, including a color-blind safe one.

Clean up in place

Right-click for Open, Show in Explorer, Properties, copy, filter to this file type, select the whole folder, or move to the Recycle Bin. The map updates and the freed space shows immediately.

Drives at a glance

A side panel lists every drive with usage bars, and the largest files, folders and file types of the current scan. Click a drive to scan it.

Light, dark, and yours

Follows Windows or picks a side. A Treemap page in Settings tunes density, layout bias, padding, borders and the label font; five label sizes, outlined labels for busy palettes, and your own palettes as JSON files. S cycles styles, K cycles colors.

Remembers where you left off

Every scan is saved. The start screen lists your recent ones, one click reopens yesterday's map, and a Change color mode shows what grew, shrank or appeared since. Old saves clean themselves up after a period you choose.

In English and Norwegian

Every word in the app can be translated; Norwegian bokmål ships alongside English and follows Windows by default. Adding a language is one file, and the test suite checks nothing is missing.

Fits into Windows

SpaceSharp.exe D:\ scans straight away, a saved scan opens from the command line, and an optional "Scan with SpaceSharp" entry goes into Explorer's right-click menu for folders and drives, for your user only.

Questions

The short answers. The README on GitHub has the long ones.

Is it safe? Does it send anything anywhere?

No telemetry, no accounts, no network use except the update check, which only asks GitHub for the latest release and only when you installed with the installer. The source is public and the release assets are built from it.

Why does the fast scan ask for administrator permission?

Reading the NTFS file table means opening the drive itself rather than its folders, and Windows only allows that for administrators. When you scan a drive, SpaceSharp asks once through the normal Windows prompt, a small elevated helper reads the table and hands the map back to the window you already have, and the helper exits. Say no and the normal scan runs instead; everything else works the same.

Deleting from the map, what exactly happens?

Files go to the Recycle Bin, never straight to deletion, and the map updates to show the space as free. Protected system folders are read-only unless you run as administrator, and even then the app never touches files by itself.

Why is the total different from Explorer or from the drive's properties?

The map counts file contents. Explorer's used space also includes the file system's own structures, shadow copies and space reserved by Windows. Hard-linked data such as WinSxS is counted once here, which Explorer's folder sizes do not do.

How is this different from WizTree or WinDirStat?

SpaceSharp is about the map: zooming, styles, filtering and cleaning up in place. Like WizTree it reads the NTFS file table when run as administrator. WinDirStat is the classic and has not changed much. Use whichever fits; the table above lists the differences.

Where do the saved scans go, and can I turn that off?

In your profile's local app data, one file per drive plus the previous one for comparison. Settings › Scanning sets how long they are kept (a week to forever, 3 months by default), deletes them all in one click, and can stop the last scan from reopening at startup.

Can I use it in Norwegian?

Yes. Settings › Språk lists every language that has a translation; it follows Windows unless you choose one. Translations are plain resource files in the repository, so adding another language takes an afternoon, not a release.

What does it need to run?

Windows 10 or 11, 64-bit. The portable exe and the installer both carry their own .NET runtime, so nothing else needs installing. Around 60 MB on disk.
