# SpaceSharp file types: which extensions belong to which category.
#
# This file is embedded in SpaceSharp.Core and read once at startup. To add a file type, put its extension,
# with the dot, under the right [Category] heading. Extensions are separated by spaces or new lines, matched
# ignoring case, and anything after # on a line is a comment. The categories are the FileCategory enum:
#   Images Video Audio Archives Programs GameData Installers DiskImages Databases Fonts System Documents Code
# An extension listed twice goes to the category it is listed under last, and the tests fail on a duplicate,
# so when one extension means two things pick the category whose files are big and common on a PC and leave
# a comment. Everything not listed here is "Other".
