SpaceSharp screenshot tool (a mockup, not the app)

This is a mockup, not the app. The window is drawn in the browser by docs/spacesharp-mock.js to look like SpaceSharp with the default settings, close enough for the README, the website and store listings, but it is not a build of the app: sizes, grouping, text fitting and the panel's numbers are approximations, and it only follows UI changes when someone updates the drawing. For anything that has to be exact, screenshot the real app. Everything here is generic sample data, so nothing real ends up online. Pick a scene to stage the hover card, the right-click menu, the filter drawer or rail, the panel under the map, Inspect, a selection or a zoomed-in folder; on the plain map you can hover and click yourself. To capture, set the browser zoom so the window shows at 100% and use Win+Shift+S, or open a scene directly with ?scene=drawer&theme=light&palette=Pastel in the address bar.
